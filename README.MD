# School Coding Projects

This repository contains a small collection of Python projects created during school learning exercises. Each folder represents a different programming task focused on logic, graphics, and beginner game development.

## Project Overview

### 1. Circle
Location: `Circle/`

This project uses Python and the `math` module to check whether a point is inside, on, or outside a circle. The program asks for the original circle's center and radius, then accepts a second coordinate pair and determines its relationship to the first circle.

Features:
- Reads circle center and radius from user input
- Accepts coordinates in the format `(x,y)`
- Uses distance formula to compare the point against the circle
- Prints whether the point is inside, on, or outside the circle

### 2. Fruit Catch Game
Location: `game_fruits/`

This project is a simple arcade-style game built with `pygame`. The player interacts with moving objects on the screen, aiming to catch fruit-like targets while avoiding obstacles.

Features:
- Pygame-based graphical interface
- Menu screen with game states
- Score tracking
- Moving objects and collision detection
- Simple instructions and level screens

### 3. Home Drawing
Location: `Home/`

This project creates a simple house illustration using `pygame`. It draws a house, roof, chimney, windows, door, trees, and clouds using basic graphics primitives.

Features:
- Pygame drawing commands
- Basic 2D shape rendering
- Simple scene design
